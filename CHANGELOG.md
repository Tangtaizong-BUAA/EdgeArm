# Changelog

## 0.1.0 — 2026-09-20

- Public code release of the data-generation and final staged training mainline.
- Four frozen Run102 research checkpoints under Apache-2.0.
- Public CLI, six stage recipes, data/model cards, provenance hashes, and CPU CI.
- Training data intentionally not distributed; tests use synthetic fixtures.
- Portable benchmark replay is separate from the original independent acceptance protocol.
